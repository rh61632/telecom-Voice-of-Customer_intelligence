## 1. Pipeline Reconstruction Drift & Silent Replacement Failure

### 1.1 Architectural Origin of the Reconstruction Drift
The active manuscript (`paper/eswa_latex/manuscript.tex` and its twocolumn twin `manuscript_twocolumn.tex`) is generated by running `scripts/reconstruct_master_manuscript.py`. That script reads `paper/eswa_latex/manuscript_base_1506.tex` (a 489-line base draft), applies string replacements (`.replace()`), splices in tables from `scripts/build_full_eswa_paper.py` (`TABLE1` through `TABLE8`), and writes out the compiled LaTeX files.

Prior to `reconstruct_master_manuscript.py`, an earlier maintenance script, `paper/eswa_latex/apply_full_review_fixes.py`, had been written to apply manual review corrections to an intermediate manuscript draft. When the author implemented `reconstruct_master_manuscript.py`, four critical replacement strings were copied from partial review notes rather than verifying the exact text within `manuscript_base_1506.tex`.

Because Python's `str.replace(target, replacement)` silently returns the unmodified string when `target` is not found, **all four `.replace()` calls silently failed to execute**. As a consequence:
1. Tables 2, 3, 4, 5, 6, 7, and 8 were replaced with newly formulated tables from `scripts/build_full_eswa_paper.py`.
2. The surrounding narrative prose remained frozen in the older, uncorrected base text from `manuscript_base_1506.tex`.
3. This created massive, glaring contradictions between the tables and the narrative text immediately surrounding them.

### 3.1 Confusion Matrix vs Printed Metric Recomputations
Table 3 (`tab:perclass`, lines 309–316) prints per-class precision, recall, F1, and a $5 \times 5$ confusion matrix for the hero ensemble on the $N = 4{,}499$ seed corpus. Mathematical recomputation directly from the confusion matrix cells reveals critical calculation and rounding errors:

\end{array}$$

Recomputed vs Printed Metrics:

1. **Class $\mathcal{C}_1$ (App Login):**
   - Predicted Positive (Column 1 Sum) $= 400 + 0 + 0 + 0 + 7 = 407$.
   - True Precision $= \frac{400}{407} = \mathbf{0.982801... \approx 0.9828}$.
   - **Printed Precision in Table 3:** $\mathbf{0.9528}$ (a $-0.0300$ typo).
   - Actual Recall $= \frac{400}{400} = 1.0000$ (Printed Recall: $1.0000$).
   - True F1-score $= \frac{2 \times 0.982801 \times 1.0}{0.982801 + 1.0} = \frac{800}{807} = \mathbf{0.991326... \approx 0.9913}$.
   - **Printed F1-score in Table 3:** $\mathbf{0.9912}$.
   - **Internal Inconsistency:** If Precision were truly $0.9528$ and Recall $1.0000$, the harmonic mean F1 would be $\frac{2 \times 0.9528 \times 1.0}{1.9528} = \mathbf{0.9758}$, not $0.9912$.
2. **Class $\mathcal{C}_5$ (General Appreciation):**
   - Predicted Positive (Column 5 Sum) $= 0 + 0 + 0 + 0 + 2687 = 2687$.
   - True Precision $= \frac{2687}{2687} = \mathbf{1.000000 \approx 1.0000}$ (zero false positives predicted for $\mathcal{C}_5$).
   - **Printed Precision in Table 3:** $\mathbf{0.9993}$.

   - Sum of printed precisions: $(0.9528 + 0.9453 + 0.9775 + 0.9837 + 0.9993) / 5 = \mathbf{0.97172}$ (verifying the macro average was computed by averaging the flawed printed numbers).
   - Sum of true precisions: $(0.982801 + 0.945312 + 0.977477 + 0.983730 + 1.000000) / 5 = \mathbf{0.977864 \approx 0.9779}$.
