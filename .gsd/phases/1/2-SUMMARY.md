## 2. Key Empirical Findings & Verified Truths

### 2.1 Visualizations & Asset Parity
- **100% SHA256 Byte-for-Byte Mirroring:** Computed SHA256 hashes across all 20 PNG plot files in `scraped_data_global/plots/` against `assets/plots/`. Every pair is byte-for-byte identical.
- **Plot Alias Taxonomy:** The 20 PNG files represent 10 distinct underlying visualizations, with dual `save_plot()` invocations creating aliases for documentation/README rendering (e.g. `monthly_nss_trend_line.png` == `monthly_nss_trend_all_months.png`; `monthly_sentiment_trend_line.png` == `multi_year_sentiment_trend_line.png` == `yearly_sentiment_trend_all_years.png`).
- **Pipeline Constants & Resolution:** In `scraped_data_global/pipeline/generate_global_visualizations.py`, target DPI is strictly set to `dpi=300` with `bbox_inches="tight"`. Operator brand colors are Grameenphone `#0090ff`, Robi `#e60000`, Banglalink `#ff7a00`.
- **Common Window Uncommitted Drift:** `generate_global_visualizations.py` contains uncommitted working-tree edits transitioning the header docstring, titles, and fallback start date from `Jul 2016` (3,716 days, N=655,670) to `Aug 2016` (`2016-08-01`, 3,713 days, N=655,649).
- **Brand Logos:** All three operator logos in `assets/logos/` (`gp.png`, `robi.png`, `banglalink.png`) are 1000 × 1000 RGBA square images with alpha transparency.
- **Paper Figure Cross-Reference:** Publication figures generated by `scripts/generate_paper_figures.py` (`figure1` through `figure4`) use serif typography (`Times New Roman` / `DejaVu Serif`) and exhibit identical SHA256 checksums across `paper/figures/`, `paper/eswa_latex/figures/`, and `paper/telecommunications_policy_latex/figures/`.
- **Plot Overwrite Divergence Risk:** `scripts/generate_two_panel_figure.py` saves to `scraped_data_global/plots/monthly_nss_trend_modern_era.png` and `assets/plots/monthly_nss_trend_modern_era.png` but does not update `monthly_nss_trend_2020_2026.png`. Executing this script would break the verified 100% parity between alias pairs.

### 2.2 Historical Archive Lineage & Dead Paths
- **`archive/seed_pipeline_groq/`:** Preserves Phase 1 Groq seed labeling (`N=4,500`). Code (`02_classify_reviews_mygp.py:50`, `myrobi.py:55`, `mybl.py:56`) uses `model="qwen/qwen3.8-27b"`, whereas `paper/eswa_latex/manuscript.tex:254` claims `Qwen-2.5-32B`.
- **`archive/scraped_data_2020/`:** Preserves 402-day common window dataset (`N=83,417`: GP=21,524, Robi=33,825, BL=28,068), Apple App Store iOS probe (`N=1,199`), and legacy 600-sample draft plan.
- **`archive/robi_backfill/`:** Preserves 37,153 reviews (`~37.1k`) and `backfill_robi_gap.py` which resolved a historical 10-month gap (Sep 2024 to Aug 2025).
- **`archive/early_dl_experiments/`:** Preserves Colab notebook proving frozen BUET BanglaBERT embeddings scored only 74.88% CV accuracy vs 85.27% for end-to-end 12-layer fine-tuning.
- **`archive/powerbi_dashboard/`:** Preserves GIF demos (`page1_demo.gif`, `page2_demo.gif`) and rationale for moving to reproducible Python Matplotlib 300 DPI figures.
- **Critical Dead Path in `ml/train_filtered_experiments.py:19`:** Hardcodes `GOLD_CSV = PROJECT_ROOT / "scraped_data_2020" / "gold_set" / "gold_set_verified.csv"`. Neither the directory nor the file exists, causing `evaluate_on_gold_standard()` (lines 138-140) to silently exit and return `(0.0, 0.0)`.

### 2.3 Dependency Reconciliation & Harness Integrity
- **5 Undeclared Runtime Dependencies:** `nltk`, `python-docx` (`docx`), `openpyxl`, `Pillow` (`PIL`), and `huggingface_hub` are imported in code but omitted from root `requirements.txt`.
- **Demo Launch Crash Risk:** `demo/requirements.txt` omits `nltk`. Since `demo/app.py:13` imports `ml.language_detector` which requires `nltk`, any isolated demo installation crashes with `ModuleNotFoundError: No module named 'nltk'`.

- **Version Specifier Inconsistency:** `scikit-learn>=1.4.0` in root, `ml/`, and `dl/` vs `>=1.3.0` in `demo/requirements.txt`.
- **Harness Status:** `VERSION` is `1.6.0`. `scripts/validate-all.ps1` runs 5 child validators across 27 workflows, 12 skills, 5 subagents, 24 templates, and 11 scripts with 0 errors and 0 warnings.
